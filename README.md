# Laal Kapda – Mobile Product Page (UI/UX Minor Project)

A clickable mobile e-commerce product page for **Laal Kapda**, a handloom brand from Odisha. Hero product: *Sambalpuri Ikat Silk Stole*.

**Author:** Gargi Agrawal · **Program:** UI/UX Internship, October Batch · Naviotech Solution Pvt Ltd

## Problem
Shoppers on small screens can't judge colour, fabric or delivery time before buying, so they hesitate and leave.

## What's in the prototype
- Swipeable gallery with live colour swatches
- **Feel the weave**: tappable hotspots explaining motif, sheen and edge
- Length options, wishlist, PIN-code delivery estimate
- "Meet the weaver" story card, true-to-colour review meter, "Style it with" row
- Confirm-options bottom sheet and bag screen

## How to run
Open `index.html` in any browser (best in phone view, or on a phone). No installation needed.
